# Sales Performance Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze e-commerce sales performance, identify key trends, and provide actionable business insights.

## Tools & Technologies Used
* **Visualization:** Power BI
* **Data Source:** Sample Superstore Dataset (CSV)
* **Data Cleaning & Transformation:** Power Query

## Key Insights & Features
* **Sales Trends:** Visualized total sales, profit, and order volume over time.
* **Regional Performance:** Analyzed performance metrics across different regions and customer segments.
* **Product Category Analysis:** Identified top-performing product categories and sub-categories.

## Project Structure
* `Sales_Dashboard_Project.pbix`: Power BI dashboard file.
* `SampleSuperstore.csv`: Raw dataset used for analysis.
